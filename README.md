# Multiple Object Detection 🎯

## 📌 Overview

This project uses **YOLO, Computer Vision, and Streamlit** to detect multiple objects in images. The interactive web application allows users to upload images and view detected objects with bounding boxes and confidence scores.

## ✨ Features

- Detect multiple objects in a single image
- YOLO-based object detection
- Image upload through Streamlit
- Bounding boxes around detected objects
- Confidence scores for each detection
- Interactive web interface using `app.py`
- Image processing with OpenCV

## 🛠️ Technologies Used

- Python
- YOLO
- Ultralytics
- OpenCV
- Streamlit
- Computer Vision
